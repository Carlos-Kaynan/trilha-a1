# Trilha A1 · Inglês do zero

Uma trilha de 12 aulas de inglês nível A1 que funciona direto no navegador. Cada aula tem:

- vocabulário com áudio
- gramática
- diálogo para shadowing
- escrita
- prática de fala
- quiz

O site também tem revisão espaçada e um caderno de palavras.

- Site estático: só um `index.html`, sem servidor.
- O progresso fica salvo no navegador de cada pessoa (localStorage).
- Hospedado no GitHub Pages.

## Rodar no computador

Abra o `index.html` no navegador.
